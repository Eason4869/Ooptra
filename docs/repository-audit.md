# 三渠道同步审查

日期：2026-10-07。范围以审查开始时的 252 个 Git 跟踪文件为准，新增修复、测试与生成工具亦纳入复审；部署机器的配置、账号和用户数据不在改写范围。

## 覆盖与方法

| 文件范围 | 审查内容 |
| --- | --- |
| 根目录入口、脚本、示例、依赖、Git 规则、CI | 启动与部署约束、环境覆盖、秘密排除、配置说明与验证流程 |
| `src/core`、`src/webui` | 代理、配置读写、认证、共享密码、API 输入、更新备份、恢复健康检查 |
| `src/voice_agent`、SDK 语音服务与 transport | 进退房、取消与回滚、跨线程音频、模型资源、自动串门与会话控制 |
| `src/bridge`、`src/oopz`、`src/onebot_v11`、SDK | 凭据持久化、事件转发、消息与图片转换、ID 映射及网络异常 |
| WebUI HTML／CSS／JS、SVG、预览页 | 当前功能与入口、主题、表单、请求与错误状态、离线资源和演示隔离 |
| 使用指南、README、CHANGELOG、设计档案 | 当前说明与代码一致性、本地链接、渠道与版本；历史记录保留原语境 |
| 测试 | 对照风险链路查覆盖遗漏，新增针对性回归；完整 Python 与真实浏览器检查 |

全清单检查包括 Python 语法和 Markdown 本地链接；对高风险模块深入检查控制流与边界。大型 SDK 模型和历史测试的清单／静态扫描不等于逐行语义证明。没有发现变化的文件保留，不为制造改动而重写。

## 修复清单

| 问题 | 修复方向 |
| --- | --- |
| 独立预览停留在旧版 | 从正式 HTML、CSS、JS、SVG 和配置白名单生成，自带隔离演示接口；CI 检查过期并执行离线浏览器验证 |
| 恢复端点忽略部署环境覆盖 | 按实际运行的地址、端口及共享密码优先级检查健康状态 |
| Windows 短暂文件占用使维护状态写入失败 | 对共享冲突进行有界原子替换重试；持续权限错误明确失败且保留旧文件 |
| 无效记忆删除请求变为全量清空 | 拒绝非法 JSON、非对象和过大请求，保留明确空体全清契约 |
| 特殊配置定义被覆盖或假保存 | 安全识别配置绑定，无法可靠定位时拒绝写入，不追加覆盖已有组 |
| IPv6 与特殊字符代理失效 | 保留 IPv6 方括号并正确编码认证组件 |
| PCM 跨线程直接操作 asyncio 队列 | 在所属循环调度入队并忽略关闭后的迟到帧 |
| 取消进房留下成员登记 | 回收已经取得的资源、清理失败保留可重试状态，并传播取消 |
| 取消代理 WebSocket 建连泄漏会话 | 建连取消也关闭未交付的 HTTP 会话 |
| 未进房的快捷开口仍请求模型 | 请求模型前验证房间与播放状态，失败不写记忆 |
| 凭据只写部分字段却返回成功 | 限定目标配置组，验证必要更新并原子保存 |
| 私聊提及成员类型不匹配 | 使用 SDK 的提及模型，覆盖 CQ／JSON 与相应协议路径 |
| 昵称查询瞬时失败阻断消息 | 对可恢复资料故障降级转发，真正鉴权错误继续传播 |
| 并发 ID 创建冲突 | 串行化数据库分配，复用已存在的映射并处理数字碰撞 |
| 示例与维护说明陈旧 | 更正代理、意图判断说明，移除未读取的环境变量示例，补齐预览生成说明 |

## 发布与验证约束

三个渠道仍为 `main`（3.2.1）、`beta`（261007.2-beta）、`dev`（261007.2-dev），正式版比较基线为 3.2.1。代码、资源、依赖、测试、CI 与 README 保持相同，仅运行版本和当前 CHANGELOG 标题区分渠道。

发布前运行 Ruff、预览生成校验、完整 Python 测试、正式界面和离线预览浏览器验证，推送后按三个准确目标提交核对 GitHub Actions。测试使用合成凭据、模拟模型、线程及本地服务；实际 Oopz 房间、模型服务与用户部署环境仍需各自的运行验收。

本地最终结果：Python 3.10 与 3.12 各 870 项通过、2 项跳过；Ruff 与预览同步校验通过；正式 WebUI 和离线预览的真实浏览器交互通过。离线预览包含 390 px 手机布局检查且无真实网络请求；独立复审运行 125 项相关回归后未发现修复范围内的剩余必须修复项。CI 的最终结果以各渠道最新目标提交对应的 Actions 记录为准。
