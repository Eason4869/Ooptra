# 语音与 API 指南

[返回 README](../README.md) · [配置与维护](operations.md) · [配置模板](../config.example.py)

## 开启与操作

语音默认关闭。先按 [README](../README.md#快速开始) 安装可选依赖，再完成以下设置：

1. 「配置 → 语音模型」：开启语音，设置后端、API Key、模型、音色及必要的代理。
2. 「语音台 → 会话控制」：选择域与频道，手动进房／退房；域 ID、频道 ID 可一键复制。
3. 「房间成员」查看成员状态，「人格与记忆」管理提示词与共享记忆。

「设为默认」会写入 `OOPZ_CONFIG.default_area` / `default_channel`，供未指定目标的插件调用使用。
bot 只监听当前加入的频道；`listen_only_uids` 留空时接收房间主讲人的音频，填写后仅监听指定成员。

## 后端与手动开口

| 后端 | 配置值 | 特点 |
| --- | --- | --- |
| Gemini Live | `gemini_live`（默认） | 语音进、语音出；需要 Live 模型配额与可达的网络 |
| MiMo 级联 | `mimo_cascade` | ASR → LLM → TTS；延迟通常更高 |
| OpenAI Realtime | `openai_realtime` | 仅有骨架，暂不可用 |

「与 AI 对话」需要已经进房：Gemini 将文字作为当前对话的一轮输入并用语音回答；MiMo 直接朗读输入文字，不经过语言模型。

Gemini 根据输入音频选择语言，人格后会追加中文普通话约束，但外语或音乐仍可能影响输出。
可进一步限定监听成员，或在人格中强调语言要求；`Live 回合：` 日志包含输入转写与回复，便于排查。

## 回复频率与强制关键词

在「配置 → 语音模型」设置，保存后对后续回合生效：

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `reply_probability_percent` | `30` | `0～100` 的回复概率；不是每十句固定回复三句 |
| `force_reply_keywords` | `[]` | 转写包含任一关键词时绕过概率限制 |

WebUI 的关键词用英文逗号分隔，例如 `Ooptra, 机器人, 小欧`。匹配忽略大小写、全半角、空格与标点，
`OOPTRA`、`Oop tra`、`Ｏｏｐｔｒａ` 均可匹配 `ooptra`；同音识别别名需自行加入列表。

`0%` 时仅命中关键词才自动接话，`100%` 时每次均允许回复；手动开口、进退房台词和语音退房控制不受限制。
旧配置缺少概率字段时采用 `30`，已有明确设置保留。

### 两种后端的差异

- **MiMo**：关闭语音退房控制且无关键词时，在 ASR 前决定是否跳过；否则先识别，再决定是否普通回复。
- **Gemini**：持续听取对话，按回复回合决定是否播放，因此降低频率不保证减少模型用量；跳过的回复不写入共享记忆。

Gemini 的输入转写与回复消息[不保证先后顺序](https://ai.google.dev/api/live)。
未播放的回复最多缓存 4 MiB，结束后保留 2 秒等待迟到转写，命中关键词后完整播放。
超时、超限或新一轮语音导致归属不明时，仅按概率处理，不把上一句关键词用于下一句。

## 语音控制退房

`voice_leave_enabled` 默认 `True`，旧配置缺项也开启；可在「配置 → 语音模型」关闭。
所有当前监听的成员均可发出请求，AI 判断是否为当前针对 bot 的退房意图，例如“退语音”“机器人，你先下吧”。
否定、引用、讨论指令或人类自己离开不应触发；实际识别效果取决于模型与 ASR，首次使用请在语音房验证。

识别后停止普通回复，随机使用所在域的自动串门 `leave_prompts` 并按人设改写，播放完离场语再退出。
空列表时使用默认“拜拜，我下了”；生成／播放失败或 20 秒超时后仍尝试退出。
成功后进入该域的**手动退房冷却**，不受普通回复概率限制。

退房期间暂停接听。WebUI／QQ 手动进退房会取消旧任务，避免旧任务退出新房间；
实际退房失败时保留房间状态与错误，并恢复接听以便重试。

| 后端 | 条件与影响 |
| --- | --- |
| MiMo | 每句先做 ASR 与独立 AI 意图判断，会增加用量；判断失败或超时不执行退房 |
| Gemini | 使用 [Live 工具调用](https://ai.google.dev/gemini-api/docs/live-api/tools)，模型或中转需支持；切换开关会重建当前模型会话 |

MiMo 的短语音控制入口最低为 250 毫秒（用户更低的设置保留）；未命中退房意图的短句仍受普通回复时长阈值约束，能量过滤仍生效。

## 抢话打断

`barge_in` 默认开启，`barge_in_hold_ms` 默认 300 毫秒。连续说话达到门限才打断 bot，人多时可适当调高。
Live 模式由客户端清空当前播放并丢弃本回合剩余音频，服务端使用 `NO_INTERRUPTION`，避免背景人声持续打断生成。
客户端不发送人为的“说完了”信号，避免缓冲音频碎片被误判为完整回合。

## 无人自动退房

无论通过 WebUI、QQ 插件还是自动串门进房，确认房间只剩 bot 自己持续 **30 秒**后，会复查成员并静默退出，不播放离场语。
有人回来、成员查询失败或无法确认 bot 自己的身份与房间时，重置计时；其他 bot 也算成员，不会被忽略。
进退房和换房会清除旧计时，避免旧房间的检查退出新房间。

此规则固定生效，不依赖自动串门的域开关、暂停状态或每日额度。
自动加入的房间退出后进入全实例自动冷却；手动加入的房间退出后进入该域手动冷却。
无人退房失败会保留实际房间状态与错误，两类房间都会在再次确认独处 30 秒后重试。

## 自动串门

需要可用的语音后端及语音总开关。在「语音台 → 自动串门」逐域开启；所有域默认关闭，旧 `auto_join` 已移除，残留字段忽略。

| 规则 | 默认行为 |
| --- | --- |
| 检查 | 全实例每 10～20 分钟随机检查一次，不会有人就立即进房 |
| 随机选择 | 符合条件且有真人的域等概率被选中，再随机选域内房间，按该域概率决定是否加入；默认 20% |
| 停留 | 10～20 分钟；到期最多等当前 bot 回复 30 秒，再进行告别，告别生成与播放最多 20 秒 |
| 自动退房冷却 | 全实例 30～60 分钟；仍允许手动进房 |
| 手动退房冷却 | 刚退出的域 2～4 小时，其他开启域仍可自动加入 |
| 每日上限 | 北京时间自然日全实例 3 次成功自动进房；可另设域上限；`0` 为不限；手动进房及已确认失败不计数 |
| 空房 | 房间只剩 bot 自己，持续确认 30 秒后复查并静默退出；查询失败视为未知 |

检查间隔与总上限为实例级设置，其他策略可按域覆盖，取消覆盖恢复继承。

### 进退房台词

每行填写一条表达意图，支持多条随机选择，每次由当前 AI 按人设改写：

- MiMo 使用文字生成与 TTS。
- Gemini 使用当前 Live 会话生成语音，无需额外 MiMo 密钥。

自动串门的空台词列表表示静默；**语音指令退房**的空列表则使用默认告别。
合成失败仍按停留／退出规则继续，台词不作为用户记忆，也不携带其他房间的聊天历史。

### 暂停、关闭与手动接管

暂停只阻止新的自动加入，当前自动停留仍按规则结束；恢复保留次数和冷却。
关闭域开关会告别退出该域的自动房间。手动房间不受自动停留时限或域开关影响，也不会自动换房，但同样遵循[无人退房规则](#无人自动退房)。
退出失败保留实际房间状态，并暂停后续自动加入。

### 状态异常与恢复

状态损坏、磁盘写入失败或中断进房留下未确认记录时，自动加入暂停；文字桥接与手动操作仍可使用。

1. 检查控制台与日志，核对账号实际所在房间并手动退出。
2. 停止程序，备份 `data/voice_auto_visit.json`。
3. 有未确认记录时，保守核对并补记当天成功次数及对应域次数，保持 `confirmed` 与计数一致，再清理对应 `pending`。
4. 修复文件后重启或点击恢复；未核清的记录继续保持暂停。

不要删除状态文件绕过当日额度。首次联调应分别验证 MiMo／Gemini 的进房问候、告别尾音、手动接管、空房退出及重启后的额度。
设计与验收记录见[需求说明](superpowers/specs/2026-10-06-voice-auto-visit-design.md)、
[实施计划](superpowers/plans/2026-10-06-voice-auto-visit-brand-release.md)和[更新日志](../CHANGELOG.md)。

## HTTP API 与插件

优先使用 WebUI 端口（默认 `3090`），鉴权令牌为 `WEBUI_CONFIG.token`。
以下路径均有等价的 `/api` 前缀别名，例如 `/api/voice/status`。

```http
GET  /health
GET  /voice/status
GET  /voice/members?area=&channel=
GET  /voice/channels?area=
POST /voice/join              {"area":"","channel":""}
POST /voice/leave
POST /voice/speak             {"text":"..."}
GET  /voice/auto-visit
POST /voice/auto-visit/config  {"updates":{...}}
POST /voice/auto-visit/pause
POST /voice/auto-visit/resume
GET  /oopz/areas
GET  /oopz/channels?area=
GET  /persona
PUT  /persona
GET  /memory
POST /memory
DELETE /memory
```

`VOICE_API_CONFIG` 提供同路由、同响应的独立端口，默认 `3091`、关闭；开启后使用其自己的 `token`，留空则无鉴权。

例如 [astrbot_plugin_ooptra](https://github.com/Eason4869/astrbot_plugin_ooptra) 默认接入 WebUI 端口，令牌填写 `WEBUI_CONFIG.token`；
只有使用独立端口时才改填 `VOICE_API_CONFIG.token`。绑定所需域与频道 ID 在「会话控制」复制。
