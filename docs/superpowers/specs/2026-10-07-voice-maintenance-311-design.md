# Ooptra 261007-beta 语音体验与维护中心设计

目标：完成用户选定的连续对话窗口、代码优化、一键语音自检、无人退房状态展示、浏览器试听、更新与备份中心及 WebUI 优化。保留已有功能；验证后直接推送 dev，开发版本统一 261007-beta，正式版比较基准仍为 3.1.0。

## 1. 已确认范围

- MiMo 与 Gemini 均支持连续对话；命中现有强制关键词后开启 30 秒窗口，窗口内追问绕过回复概率，后续有效追问延长窗口。开关与时长可配置；退房、换房和切换后端清除。
- MiMo 按成员隔离窗口。Gemini 使用音频接收侧成员信息保守关联；多人重叠或迟到转写无法确认归属时，不凭猜测为其他人开启窗口，现有关键词直接回复仍保留。
- 语音控制退房、手动开口、自动进退房台词继续不受概率限制。
- 更新中心包含一键升级、失败回滚；先支持 Git＋Python 虚拟环境部署，其他环境明确显示不支持的原因及手动指引。
- 试听在当前浏览器播放。MiMo 合成改写后的台词；Gemini 建立独立临时会话，不加入语音房、不修改实际对话记忆或房间状态。
- Logo、暗色模式及所有已有控制保留，低频配置放入高级设置；不增加无关模型、人格预设或新的串门时间规则。

## 2. 语音可靠性与代码优化

抽出独立的接话策略、诊断、试听、维护服务与前端模块，减少继续扩张 agent.py 和 app.js。沿用房间操作锁、任务所有权与 operation_epoch，保留 Python 3.10 的取消回归。

Gemini 重连增加有限次数、指数退避及状态记录；认证／协议问题与临时网络故障分别显示，不形成无上限重试。主动关闭禁止旧任务恢复。记录模型连接状态、最后错误以及最近回合阶段耗时，不承诺回复概率能够降低 Live 计费。

记忆读取使用有界保留，避免为了最近 30 条把全文件加载到内存；保持现有 JSONL 与外部插件接口，不强制迁移数据库或改变共享记忆语义。

## 3. 一键语音自检

分为本地检查与显式模型连接检查：Python／依赖、Playwright Chromium、Oopz 连接、模型密钥与配置、代理配置、模型连接及实际房间状态。返回逐项通过／失败／未检查、耗时、可操作的说明。只检查与当前后端相关的条件。

模型检查使用独立短会话或有限请求，有超时且清理资源；不进房、不向房间播放、不修改实际会话。UI 提示网络检查可能产生少量模型调用。

## 4. 无人退房状态

在当前会话直接展示是否监控、成员状态已知／未知、独处开始时间、剩余秒数、最近查询与退房错误、最后退出原因。剩余时间依据服务端时钟计算；前端只作倒计时显示，不触发退房。

沿用固定 30 秒规则：手动／自动都适用；有人回来、查询失败、换房重置，最后再次复查；其他 bot 算成员；静默退出；保持原自动全局冷却与手动分域冷却。

## 5. 台词与音色试听

语音台增加浏览器试听面板：当前后端、音色、普通短句／进房台词／退房台词、文本与播放／停止。自动台词使用已保存的配置；支持随机选择现有多条台词。进退房台词保留 AI 改写，普通音色短句用于了解音色。

返回有长度与时长上限的 WAV 音频与实际改写文本。串行生成，防止重复点击产生并发调用；超时或浏览器取消后释放临时会话；不缓存账号密钥，也不把试听内容写入记忆。

## 6. 更新与备份中心

页面显示版本、部署方式、可升级状态、最新版本／main 提交、阶段进度、失败原因、备份列表和恢复入口。保留现有检测更新接口；明确区分正式 Release 与 main 代码更新。

### 备份

备份固定范围：config.py、private_key.py、data 中的用户状态与记忆，排除维护任务自身、缓存和日志；SQLite 使用一致性备份。备份存于本机维护目录，下载与恢复受控制台鉴权约束，UI 明确包含账号配置。只接受服务生成的备份 ID，不允许任意路径。

恢复前验证清单、文件大小与路径；拒绝 ZIP 路径穿越、链接或未声明的文件。恢复前再创建安全备份；暂停相关运行任务后恢复，采用原子替换并重启／重新载入。不要覆盖未知的用户文件或静默忽略恢复失败。

### 升级

仅允许配置为本项目 GitHub 仓库的干净 Git 部署，使用虚拟环境；检测目录写权限、Git、Python、磁盘可用空间和重启能力。预检查失败不停止服务。

升级固定到检查得到的可信仓库提交，准备新代码与隔离虚拟环境并安装依赖，通过本地启动前检查后才进入切换。备份用户数据，正常停止语音与桥接，再由独立更新进程切换代码并启动新服务。服务端健康检查必须确认新进程与版本；失败回滚旧提交、旧解释器并重新启动，进度落盘供页面恢复连接后查看。

不清除本地改动，不执行任意 shell 指令，不改写用户配置，不依赖浏览器继续打开，也不把旧进程退出等同于升级成功。对不支持的服务管理／安装方式提供明确手动步骤。

## 7. WebUI 与文案

沿用蓝色品牌，建立统一浅色／暗色状态、间距、焦点与禁用样式。语音台突出房间与操作状态，诊断／试听为二级入口；维护与备份新增独立页面。兼容手机、键盘导航和减少动画偏好，所有失败均给出下一步。

修正两处已指出的行为说明：

- “手动进房不受串门停留时限影响；只剩 bot 持续 30 秒仍会自动退出。”
- Gemini 的文字开口显示“AI 语音回答”；MiMo 显示“直接朗读”，按钮与说明同步切换。

## 8. 验收与发布

- 回归现有进退房、冷却、限额、概率、关键词、语音退房、暗色模式与插件 API。
- 新测试覆盖成员窗口隔离／到期／重置、迟到转写与重叠发言、无人倒计时未知状态、自检与试听资源清理。
- 维护测试覆盖权限不足、脏工作树、错误仓库、备份路径／一致性、依赖安装失败、健康检查失败与回滚；在临时测试仓库演练，不升级当前开发仓库。
- 前端使用桌面／手机及浅色／暗色截图检查，验证真实请求与音频控件；自动验证不能替代真实 Oopz 房间和真实 API 的人工体验。
- Python 3.10／当前环境完整 pytest、Ruff 与 GitHub CI；README、指南、CHANGELOG、版本显示更新为 261007-beta，直接推送 dev；不修改 main。

实施分为独立可验收的语音策略、诊断与试听、维护服务、前端与发布四部分。
