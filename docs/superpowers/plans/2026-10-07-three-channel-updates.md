# 三渠道更新部署实施计划

用户已确认 main 为正式版、beta 为测试版、dev 为预览版；默认跟随安装渠道，允许明确确认后切换。版本分别保留 3.1.0、261007-beta、261007-dev。

1. 在独立工作区保留三个分支的基线。仅修改更新、安装、健康检查、对应界面、测试及获取代码说明。
2. 更新检查统一支持三个渠道；已安装渠道与目标渠道分开显示。后端绑定检查时的提交、当前版本和渠道，阻止失效检查及未经确认的跨渠道安装。更新后的渠道持续保存。
3. 独立环境准备和安全备份完成后才关闭服务；本地初始化与桥接监督任务就绪才通过健康检查。Oopz/OneBot 外部断连仍视为降级，不自动回滚。
4. 为 main 补入更新部署所需的启动器、维护接口与界面；beta 使用同一更新链路。保持原有语音、桥接与其他前端功能。
5. README 获取代码列出三渠道明确的 clone -b 命令，说明虚拟环境、launcher.py、服务账户权限和局域网访问。
6. 先验证新增回归测试失败，再修复；执行各分支完整测试、前端交互、静态检查和更新/回滚演练，审查分支差异后分别推送，核查远端 CI。

验收重点：beta 不再被识别为 dev；切换需确认；代码改变后旧检查不能部署；尚未初始化的 WebUI 不被判为启动成功；其他功能代码不被跨分支覆盖。
