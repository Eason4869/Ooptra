# OneBot 图片发送与历史 CI 核对

版本保持 `261007-beta`，发布到 `dev`。

## 原因与范围

AstrBot 4.28.2 的 aiocqhttp 发送器把图片转换为 `base64://…`。Ooptra 原先把它当作 Oopz 上传编号，既无可读取的图片文件，也无已上传附件，导致群聊／私聊发送失败。

修复 JSON 与 CQ 图片的统一转换，复用 SDK 的后台解码、图片校验和上传链路。兼容图片 data URL、本地路径、Windows 与 POSIX 文件 URI，处理 CQ 参数转义。保留已有上传编号与 URL 的解析方式；本次不新增远程 URL 下载。

部分 AstrBot 帮助插件发送图片失败后，框架未记录成功发送，仍可能进入 LLM。修复图片链路可消除这一触发条件；不拦截所有斜杠指令，也不修改不属于本仓库的帮助插件。`/suhelp` 若仍异常，需其插件日志进一步定位。
